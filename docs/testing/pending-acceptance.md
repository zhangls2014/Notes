## 无障碍与原生窗口

来源：2026-10-01 Expressive、10-02 无障碍/API 审计及 Toast 修复。第 1–5 项代码修复和语义/原生控件回归已记录，尚未完成端到端读屏验收。

- [ ] **完整读屏流程**：TalkBack/VoiceOver 覆盖登录、搜索、详情、收藏、多选、草稿、设置、退出和个人信息；检查动作名称、遍历顺序、焦点恢复、错误/加载/保存反馈。
- [ ] **辅助输入与极端显示**：外接键盘、Switch Access/Full Keyboard Access 验证激活、弹层退出及焦点限制；测量相邻小控件的触控区域，检查系统字号×应用倍率、大字号、高对比度、Dynamic Type 和 Reduce Motion。
- [ ] **iOS Toast**：执行 [专项设备步骤](ios-toast-accessibility.md#设备验收)，确认真实声音、读屏焦点、动态字号、替换/取消播报和触摸穿透。原生 UILabel 测试与 Kotlin 编译不能代替该验收。
- [ ] **UIKit 多窗口与生命周期**：两个场景、旋转/窗口缩放、宿主后台/销毁及提示显示期间取消，验证提示属于实际宿主、关闭后不残留窗口或任务。早期 Koin 优化后的设备冷启动也缺少专项完成证据，需检查首次初始化、重复控制器创建及启动任务生命周期。

已知边界：Android 独立 Dialog/Sheet 不保证继承父组合的应用内字号倍率；通用长确认正文目前无滚动，现有生产调用是短文案。完整读屏、高对比度或所有触控区域不能由静态配色抽查证明。涉及行为修复时另行明确范围，见 [主题与弹窗回归](adaptive-ui.md#material-3-expressive-迁移2026-10-01)。

## 凭据、个人信息与关于页面

- [ ] **平台安全存储**：按 [凭据存储指南](secure-token-storage.md) 验收 Keystore 密文、密钥失效、暂时访问失败、升级迁移、退出重启和账号切换。真实 Keychain 测试在独立 Kotlin/Native 环境返回 `errSecNotAvailable (-25291)`，标记 `@Ignore`；需在可访问 Keychain 的应用宿主中验证，不能计为通过。
- [ ] **系统图片选择器**：双端验收选择、取消、保存失败/重试、保存中重复操作及读屏反馈；失败保留旧头像，返回恢复发起入口。profile 模块拆分的自动回归不替代设备流程。
- [ ] **关于页面实际包信息**：Android 调试包曾核对版本 1.0、构建号 1；iOS 安装包信息尚未验收。当前版本在双端重新核对名称、原始构建号、返回设置与导航恢复，检查展开状态播报和禁用更新入口无可执行动作；动态色视觉体验仍待验收。
- [ ] **系统启动页设备范围**：2026-10-02 已记录 iPhone 模拟器浅/深色截图；真机和 iPad 未验证。按 [启动页指南](ios-launch-screen.md) 验证资源、居中及进入应用，不把静态启动展示当作性能改善。

## 调查覆盖缺口

- 2026-09-22 Android 17 审计没有完成官方变更清单逐条核对，也没有覆盖网络、权限、后台和隐私领域；16 KB 页大小只检查整体运行，没有逐项检查 Native 库对齐与加载。后续平台兼容审计应覆盖这些范围，不能将旧报告当作完整平台验收。
- [iOS 启动调查](../audits/2026-10-02-ios-startup.md) 未验证真机脱离调试器的 Release 冷启动和全新安装。后续性能工作保持构建、设备、登录态、冷/热启动和计时阶段一致，并记录轮次及精度；已有模拟器 warm launch 结果不外推为生产性能。

# 导航转场与设备圆角

已批准并按真机反馈调整，2026-10-01。

普通进入和返回直接切换，不使用转场动画。单页预测返回以新建邮件的 Material 3 BottomSheet 作为手感参照：直接驱动绘制层，使用 CubicBezier(0.1, 0.1, 0, 1) 进度曲线，横向最大缩减 48dp、纵向最大缩减 24dp，以页面中央为缩放原点，内容补偿避免文字和图片变形。

页面基准：只缩放当前页面，侧栏及底部导航固定。缩放比例和页面中央原点以页面内容区计算，圆角边界以可见页面的实际尺寸计算，不补偿页面在窗口内的偏移；AppShell 不裁剪内容；页面自身在预测返回时裁剪可见轮廓。

拖动中直接读取 NavigationEventState 的最新进度，不再对默认弹簧做时间采样。前一场景挂载前不缩放当前页面，避免空白首帧。释放后的取消和提交使用线性 Scene timeline；收尾由预测返回的场景时间线管理。

Android 12+ 从 rootWindowInsets 读取四个 RoundedCorner，随窗口更新。拖动期间圆角半径固定使用系统提供的设备半径，不随手势进度插值；按内容比例修正后的最终缩放比例补偿圆角半径，使显示后的物理四角对应系统数据。旧 Android、系统未提供圆角及 iOS 仍有预测返回缩放，但不做设备圆角匹配。分栏、应用外壳和浮层保持原有布局与手势处理。

验证：真实导航像素测试检查逐帧不透明、拖动反向响应、取消及提交；几何测试检查物理四角及双轴缩放补偿；既有邮件返回/侧栏回归；Android 构建、lint 和 iOS 编译。

详情页安全区：全尺寸 Scaffold 将状态栏下方应用背景保留在缩放层内，内部通过 safeDrawing 和 TopAppBar 处理内容避让。状态栏时间、电量等系统图标保持系统绘制。

背景和裁剪在内容比例修正层内绘制，圆角必须位于实际可见页面四角，页面下方保持透明以显示上一页。

取消收尾：页面恢复尺寸时，圆角以独立的 220ms 动画恢复到页面原有的未裁剪轮廓。短距离拖动取消时，尺寸可能先恢复，圆角动画仍完成后再解除裁剪；再次开始手势时恢复设备半径。完成返回时保留固定圆角。详情背景使用正常主题颜色。

层次感：预测返回时在上一页上方、当前缩放页面下方绘制灰色遮罩，最大透明度 24%，随手势进度显现。遮罩不缩放、不覆盖外壳，取消或提交时在 220ms 内淡出。

# Material 3 Expressive 迁移设计

2026-10-01。用户在可行性报告与推荐实施顺序之后授权开始迁移，本设计落实该方案。

## 视觉与范围

保留现有品牌配色、动态色、深浅色和字号设置，根主题改为 MaterialExpressiveTheme，显式配置强调字体与统一形状。正文保持原有尺寸，标题和操作标签使用更清晰的字重。关键按钮使用 Material 3 的形状变化重载；不把所有操作放大，也不改变邮件阅读密度。

登录表单保持布局与滚动，替换固定按钮圆角、硬编码字体。设置列表将连续设置行组成圆角容器，危险操作单独呈现；分组顺序仍属于 feature:settings。邮件卡片采用统一圆角和主题容器色，清晰表达打开、多选和收藏状态。回复为次要 tonal 操作，草稿保存为主要操作。普通图标操作复用共享按压形变。确认对话框使用标准 AlertDialog，保留 AnnotatedString 内容、回调和显式按钮关闭语义。

## 边界

主题、字体、形状与共享控件位于 core:theme；设置行形状契约位于 core:preference。不改依赖版本、MVI、Repository、数据模型和导航策略。保留窗口事实唯一来源、ContentWidth、IME 保护、左右登录分栏和铰链规则。系统原生 UI 不受此次迁移控制。

## 验收

先增加主题配置切换的宿主测试，检查字体缩放、动态色与深浅色切换以及强调文字层级。运行既有 AdaptiveUiTest 行为断言并生成候选图，审阅紧凑、宽屏、深色与大字号页面。编译 Android 与 iOS，运行 Android lint。候选图不覆盖正式基线；记录既有截图空白问题和设备运行验证的限制。

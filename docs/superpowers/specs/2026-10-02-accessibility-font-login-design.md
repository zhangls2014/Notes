# 系统字号与登录加载无障碍修复

用户授权修复无障碍审计的前两个问题。范围为共享主题字号及登录表单，不处理 iOS Toast、头像标签和邮件动作说明。

- 系统字号是基础，现有 FontSizeConfig 的 1 / 1.5 / 2 是相对倍率。主题使用系统 fontScale × 应用倍率，保留系统 density 和既有窗口事实计算位置；不变更持久化模型。
- 登录加载期间禁用账户、密码、清空账户、密码显示切换和登录按钮，清除输入焦点。主题／语言入口仍可操作。
- ViewModel 在有效登录 Intent 的同步处理阶段设置 isLoading，防止排队 Intent 在协程启动前重复提交。加载中忽略表单编辑和再次提交；失败或取消通过 finally 恢复可用状态。
- 加载指示器增加本地化名称及 polite live region，保留 Material 的进度语义。禁用控件是阻止语义与键盘操作的依据，不依赖指针遮罩。
- 以宿主主题、UI 语义和可延迟的 Repository 测试证明字号跟随、重复提交拦截、加载时编辑限制和失败后重试；运行 iOS 编译与已有自适应测试。
- Android 独立 Dialog / Sheet 的应用字号继承边界不在本次修复范围；系统缩放及两种倍率叠加的布局须回归。

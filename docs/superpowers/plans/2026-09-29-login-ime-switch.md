# 登录键盘切换占位保护

状态：初版已由用户真机确认切换抖动消失。2026-10-01 收起滞后修正版已通过回归并更新真机，手感待用户确认。用户已选择方案 1。

## 设计

Android 登录输入框有焦点时，IME 占位增加立即生效，下降等待连续稳定 200 ms 后释放；中途新高度到来取消旧释放任务。真正关闭键盘即使保留输入焦点也会在稳定后释放。输入框失焦时停止保护。保留原有系统栏 inset 消费，不能重复计算系统栏，也不能让实际更高的键盘被延迟避让。iOS 继续使用原生 `imePadding()`。

本次只实现占位保护，不固定居中位置、不禁用自动滚动、不更改密码键盘类型。200 ms 为待受影响设备验收的初始参数。

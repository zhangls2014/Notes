# Navigation Motion Implementation Plan

**Goal:** 普通页面直接切换；预测返回以页面中心缩放、跟随手势，拖动时固定设备圆角，取消时动画恢复原有轮廓。详情安全区纳入变换，应用外壳固定。

**Architecture:** composeApp 装配 SceneState 与 NavigationEventState；单页 Scene 的绘制层直接读取手势进度，线性 timeline 管理页面收尾。背景和裁剪位于内容比例修正层，独立 Animatable 管理取消时的圆角恢复。

- [x] 普通进入/返回移除位移和透明度转场。
- [x] 页面以自身中心缩放，采用 Material BottomSheet 曲线及内容比例修正。
- [x] 前一场景就绪前保持完整页面；验证手势反向响应和提交后上一页位置。
- [x] 拖动期间设备半径固定，补偿最终缩放，使用实际页面边界裁剪。
- [x] 圆角、背景与可见页面统一，消除底部额外背景和圆角错位。
- [x] AppShell 不裁剪内部 UI，侧栏和底部导航不参与页面变换。
- [x] 详情全尺寸 Scaffold 包含顶部安全区；内部内容避让，恢复正常主题颜色。
- [x] 取消时圆角恢复动画持续 220ms；短手势尺寸先恢复时仍保留圆角动画直至结束。
- [x] 几何与像素测试覆盖固定半径、圆角恢复、中心稳定、安全区、底部透明和取消/提交。

最终验证：14 项适用测试通过，63 个既有参数组合跳过；Android 整包构建、iOS 编译和 Android lint 通过。真机用户已确认此前整体效果；最终版本包含新增取消圆角恢复与正常主题颜色。

后层背景：预测返回时在上一页上方、当前页面下方绘制最大 24% 灰色遮罩，随缩放显现并在取消或完成时 220ms 淡出；前景页面与导航保持原色。14 项相关测试通过、63 个既有参数组合跳过，Android 构建、iOS 编译及 Android lint 通过；真机覆盖安装并启动，保留现有数据。用户确认效果后将后层背景修改整理进同一个最终提交。

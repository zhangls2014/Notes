# 根导航单页场景选择

已批准，2026-10-02。状态：已完成。

目标：普通窄屏页面在高度跨过 900dp 时保持统一预测返回；保留宽屏空态和真实铰链分区。登录页内部左右分栏、竖向铰链避让和横向折痕处理不变。

实现：在 composeApp 抽出所有导航条目共用的场景装配，复用组合根的窗口事实和 directive。仅宽屏多水平分区或存在横向铰链时保留自适应单窗格场景；不把仅由高度产生的多纵向分区作为保留条件。实际多窗格继续由 Adaptive 处理，普通单页继续由 DeviceCornerNavDisplay 包装。

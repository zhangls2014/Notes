# 服务端模拟邮箱实施与验收

目标：每位登录用户拥有持久化模拟邮箱；不投递外部邮箱或其他注册用户。业务归 feature:email，网络与账号生命周期归 core:data，认证传输由 composeApp 装配，服务端复用现有认证服务和 PostgreSQL。

## 已完成

1. 增加邮件表与增量迁移，维护 OpenAPI；按用户隔离、初始化一次、幂等发送及会话关联。
2. 网络分页 Repository 替换正式入口的本地示例注入，旧 Room 文件和实现保留。
3. 发送、回复、回复全部、转发与收藏/删除/搜索接通；失败保留编辑内容。
4. Retry UI 按维护者确认的范围调整；保留搜索栏、导航、新建邮件按钮及邮件卡片尺寸与留白。
5. 按授权备份、迁移生产库，校验暂存源码并切换服务、重启及检查公网接口。
6. 更新架构、未发布记录及验证证据；本需求合并为一个最终提交，以 fast-forward 合入 master。

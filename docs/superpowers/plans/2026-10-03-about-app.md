# 关于应用页面开发方案

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. 用户已于 2026-10-03 授权开发；实现完成，验证记录见文末。

**Goal:** 实现已确认的「品牌信息卡片」关于应用页面，展示真实应用版本与图标，检查更新暂显示“即将推出”。

**Architecture:** 新增 `:feature:about-api` / `:feature:about`。现有平台版本读取留在 `composeApp`，由组合根转换为 About 的输入值；共享品牌资源归 `core:theme`，设置入口元数据归 `core:preference`，清单与行为归 settings。

**Tech Stack:** Kotlin Multiplatform、Compose Multiplatform、MaterialExpressiveTheme、Navigation 3、Koin 注解、现有 MVI 基类与 Compose Resources。

## 1. 已确认的界面与范围

- 从设置页面的“关于应用”项进入，作为普通单栏目的地。
- 顶栏使用现有 CenteredTopAppBar 与返回行为。
- 品牌卡片展示已有星形图标、本地化应用名称和“应用信息与版本更新”说明。
- 版本号默认可见，点击版本行展开或收起构建号。
- 检查更新使用禁用的 Material 3 FilledTonalButton 展示“即将推出”，当前不执行操作，不产生网络请求，不显示“已是最新版本”。
- 使用现有主题色、字重、圆角、字号缩放。内容可滚动，以 ContentWidth.Form 为宽度上限，在大窗口居中。
- 本次不增加更新服务、更新 Repository、更新记录页或数据库字段。

## 2. 模块职责与公开契约

| 所有者 | 负责内容 |
| --- | --- |
| feature:about-api | AboutDestination、AboutEntry、AboutAppInfo 输入值、AboutNavigation 序列化贡献 |
| feature:about | AboutEntryImpl、AboutScreen、私有 UI 组件、mvi/ 类型、AboutModule、aboutNavEntry |
| composeApp | 平台 AppInfo、转换输入值、Koin 装配、根导航与外壳显示策略 |
| feature:settings | “关于应用”项的顺序、OpenAbout Intent 与 SettingsResult |
| feature:main | 接收 SettingsResult.OpenAbout，转发宿主 navigateToAbout 回调 |
| core:preference | AboutPreference 的静态元数据；不持有 Intent、导航目的地或设置清单 |
| core:theme | 应用图标和本地化品牌名称等共享静态 UI 资源 |

拟定 API：

```kotlin
@Serializable
data object AboutDestination : Destination

@Serializable
data class AboutAppInfo(
  val versionName: String?,
  val buildNumber: String?,
)

interface AboutEntry {
  @Composable
  fun Screen(appInfo: AboutAppInfo, onBackPressed: () -> Unit)
}
```

AboutDestination 不实现 RequireLogin。抽象 Composable 不提供默认参数，遵循现有 Native 跨模块入口约定。AboutAppInfo 只描述该 Feature 的输入，不包含 Context、NSBundle、资源对象或 DI provider。

settings 和 main 无需依赖 about 实现；通过已有 Result 与新增宿主回调完成跳转。about 实现依赖自身 API、core:theme 和 core:framework。API 使用 me.zhangls.kmp-compose-api 约定插件；默认 implementation，公开签名出现的依赖类型按仓库规则使用 api。

## 3. 平台信息与品牌资源

复用以下现有能力：

- composeApp/src/commonMain/kotlin/me/zhangls/entry/util/AppInfo.kt
- composeApp/src/androidMain/kotlin/me/zhangls/entry/util/AppInfo.android.kt
- composeApp/src/iosMain/kotlin/me/zhangls/entry/util/AppInfo.ios.kt

在 AppInfo 增加返回原始可空字符串的 getBuildNumber()，保留 getVersionCode(): Long 的既有语义与 InitData 使用方式。Android 将 longVersionCode 转为字符串，版本名称使用 PackageInfo.versionName；iOS 分别读取 CFBundleShortVersionString 与 CFBundleVersion。组合根把空白值归一化为 null，About 显示本地化“未知”，不以 0 或示例 1.0 伪装真实值。

无需为了此页面新增 core:appinfo，也不移动现有平台实现。运行时能力通过 Entry 的值参数进入 About，页面不会反向依赖 composeApp。

品牌图标在 core/theme/src/commonMain/composeResources/drawable/ 增加共享资源，图案沿用现有星形品牌资产；不在 commonMain 获取 Android Drawable 或解析 iOS AppIcon 清单。品牌名称的英中文资源也归 core:theme，核对现有平台名称，避免出现两套不一致的应用名称。Launcher 与页面资源来源一致，平台必需的 launcher 输出继续保留。

## 4. 状态与组件

内部组件留在 feature:about/ui/，不因只使用一次就下沉到 Core：

- AboutBrandCard：图标、名称、说明；颜色消费 MaterialTheme.colorScheme。
- AboutVersionGroup：版本行、展开后的构建号、未启用的更新项。

MVI 类型统一放在 feature:about/mvi/：AboutState、AboutIntent、AboutAction、AboutReducer、AboutViewModel。AboutState 持有宿主输入与 isBuildInfoExpanded；唯一业务交互是 ToggleBuildInfo，经 Action 与 Reducer 改变展开状态。Entry 将 AboutAppInfo 作为 ViewModel 参数传入，页面按现有约定订阅 State。版本属于环境事实，更新检查当前不可用，因此不建立 Repository、UseCase 或虚假异步 Loading。

保留 MviViewModel.savedKey 默认 null。返回通过 AboutEntry 的回调交给宿主，使用 NavEffect.Popup。当前无密码等敏感状态，也没有启用跨进程保存的需求。

可访问性要求：版本行为具有按钮语义与展开状态；图标与旁边应用名称重复时可作为装饰；未启用的更新项不能获得点击语义；返回触控区域至少 48dp。新增资源占位符使用位置参数。

## 5. 导航与外壳

事件链：

```text
AboutPreference
  → SettingsIntent.OpenAbout
  → SettingsResult.OpenAbout
  → mainNavEntries(navigateToAbout)
  → AppNavHost: NavEffect.Navigate(AboutDestination)
  → AboutEntry.Screen(appInfo, onBackPressed)
```

AboutModule 注册 AboutEntry 与 AboutNavigation 的 NavigationContribution；NotesModule includes AboutModule，现有 NavigationRegistry 自动收集序列化贡献，无需手工添加另一套路由注册表。

在 AppNavHost 注册 About entry，并按个人信息页的现有策略隐藏该页的底部导航 / Rail，返回后恢复设置 Tab 与滚动位置。About 不附加列表—详情 metadata，不读取 LocalPaneScaffoldDirective，不读取或推导窗口断点，不增加铰链安全区。

# 重要决策记录

整理日期：2026-10-07。本文保留已完成需求中不能单靠源码解释的选择理由；现行实现与约束以 [架构文档](architecture.md) 和 [AGENTS.md](../AGENTS.md) 为准，未完成验证见 [待验收清单](testing/pending-acceptance.md)。本文不重列实施步骤或历史测试通过数量。

## 铰链只属于实际分栏布局

2026-09-23 的早期方案曾为导航、搜索、设置和弹层统一增加铰链安全区域，改变了普通设备的组件选择、尺寸和留白。后续决定仅让登录窗格和邮件列表—详情场景消费根节点提供的 directive，其他页面沿用标准组件。相同铰链几何下，半开和全开不能改变窗格位置。

2026-09-24 至 09-27 的登录布局复查进一步确认：登录只支持左右分栏，空间不足时单栏；横向折痕不缩减品牌与表单的可用高度。横向折痕可能穿过内容是经截图审阅接受的行为，不应再次作为缺陷引入通用安全容器。高度不足时通过滚动保留组件尺寸与间距。

来源主题：09-23 铰链隔离重做、仅分栏避让，09-24 登录居中，09-25 自适应审计。最终约束见 [自适应布局](architecture.md#自适应布局)。

## Tab 状态与页面动画分开管理

2026-09-28 第一版仅保存活动 Tab 的返回栈，切换后回到根页面；用户随后要求恢复滚动、多选和详情，因此改为各 Tab 独立保存栈及 Entry 状态。Tab 根之间仍没有返回历史，退出登录清空所有栈。多选等 ViewModel 状态留在当前进程，不借此扩大 MVI 跨进程保存范围。

列表首次加载指示曾作为唯一列表条目，把待恢复的滚动索引压回 0；将其放在列表外后恢复测试通过。导航动画后续已调整为 Tab Fade through 和单页中心缩放，早期“全部直接切换”的设计不再是现行规则。具体行为与几何参数见 [Navigation 3](architecture.md#navigation-3)，中间帧回归见 [自适应 UI 指南](testing/adaptive-ui.md)。

## 输入框交接保护只覆盖短暂切换空档

2026-09-29 的 Android 保护对全部 IME 高度下降等待 200 ms，解决了普通键盘与安全键盘切换抖动，但用户反馈正常收起滞后。2026-10-01 改为仅在焦点交接后的 400 ms 内保护下降，窗口外正常收起逐帧跟随真实 inset，并将能力共享给登录和新建邮件。

切换后立即关闭键盘仍可能落入有限保护窗口，是区分交接空档与真正关闭的取舍。iOS 保留原生处理。宿主注入不能模拟厂商安全键盘进程，实际手感单独验收。策略与消费边界见 [自适应布局](architecture.md#自适应布局)。

## 搜索宽度以组件自然测量为基准

2026-09-28 的修复选择首次空查询测量作为锚点基准，避免长查询把搜索框撑宽，同时避免复制 Material 默认宽度或强制填满窗口。测量副本不绘制、不参与焦点和读屏，也不修改真实查询。窗口收窄时临时服从父约束，密度、字号、方向和提示变化时重测。布局与恢复回归见 [搜索框首次测量宽度](testing/adaptive-ui.md#搜索框首次测量宽度2026-09-28)。

## Expressive 主题与无障碍分别验证

2026-10-01 的迁移在当时依赖中已具备共享 API，无须以升级或导航重构为前置条件。主题不会自动把普通按钮变成按压形变按钮，也不会自动提供完整强调字体或设置分组，因此在 theme/preference 边界显式统一字体、形状和控件；保留品牌色、正文密度与 Feature 行为。

2026-10-02 确认应用字号应是系统字号的相对倍率。登录加载期间通过禁用输入及动作、同步拦截重复 Intent、提供命名加载状态约束操作，指针遮罩不能代替键盘和语义操作限制。邮件动作标签随普通/多选模式和选中状态变化；收藏列表不暴露无效选择动作。系统原生 UI、独立弹窗和读屏需要各自验收，不能由主题迁移或语义测试替代。

## 凭据与用户资料分离

2026-10-02 将整组账号凭据交给 `core:data` 的平台安全存储，资料模型及 UI State 不携带 Token。永久密钥失效和暂时访问失败分开处理，安全存储错误不回退明文；迁移安全写入并读回确认后才清除旧字段，仓库串行协调登录、退出和资料更新。

iOS 选择 `WhenUnlockedThisDeviceOnly` 并关闭同步；将来需要锁屏后台同步时，应重新评估可访问性。旧资料文件排除备份，也使普通设置不能经该文件备份迁移；已经存在的旧备份不能追溯清除。当前没有真实刷新协议，不添加猜测的刷新端点。实现边界见 [数据与资源规则](architecture.md#6-数据与资源规则)，平台验收见 [凭据存储指南](testing/secure-token-storage.md)。

## 平台服务由入口与宿主拥有

2026-09-25 移除启动任务及平台桥接中的全局服务定位器，依赖改为构造注入，由入口决定初始化与协程生命周期；同时开启组合根和网络模块的 Koin 编译安全检查。纯策略、短暂 UI 状态及窗口事实不因为“用了 DI”就注册成单例。

2026-10-02 的 API 修复进一步让 iOS 每个 Compose 宿主持有 Toast presenter，通过实际 windowScene 定位，而不是读取全局屏幕或任意场景。动态字体与 announcement 不主动抢读屏焦点；宿主关闭、替换与取消负责清理窗口和待播报任务。系统 Launch Screen 只改善加载期间展示，不证明启动速度优化。细节见 [Koin 装配](architecture.md#koin-装配)、[Toast 验证](testing/ios-toast-accessibility.md) 和 [启动页指南](testing/ios-launch-screen.md)。

## 个人信息与关于页面保持独立 Feature 边界

2026-10-03 个人信息初版属于 settings，后续拆到 profile API/实现。两个入口共享只读资料与头像修改页面，返回恢复发起 Tab；旧目的地序列化名称保留，避免模块移动破坏已保存的返回栈和登录重定向。头像先复制到唯一私有路径并原子提交，再清理旧文件；取消或账号变化不提交失效快照。

关于页面选择由组合根传入实际安装包版本和原始字符串构建号，避免 Feature 重复读取平台信息或把 iOS 点分构建号当整数。更新功能尚无明确来源与渠道，因此只显示禁用的“即将推出”，不添加闲置服务或网络接口。两页隐藏导航套件，但保留 Entry 与 Tab 状态。设置的清单、顺序和值映射继续归 settings，通用渲染归 preference。

## 本地构建与升级以明确边界为依据

2026-09-23 的 worktree 验证表明：缺 `local.properties` 本身不会阻止 Debug 构建，实际失败来自没有可用 SDK 路径。SDK 发现交给 AGP。当时允许缺少正式签名配置的 Debug 构建；这一历史行为已被取代。当前 Debug/Release 共用正式签名，只从 Gradle 属性或环境变量读取，缺失或无效时构建失败，不再读取旧本地文件。当前配置说明见 [本地配置](../README.md#本地配置)。

2026-10-07 升级最终以官方支持范围和最高测试版本的交集为上限；项目实测成功不能扩大上限。长期选择流程见 [升级规范](dependency-upgrades.md)，当次版本、失败与环境缺口保留在 [升级记录](audits/2026-10-07-dependency-upgrade.md)。
